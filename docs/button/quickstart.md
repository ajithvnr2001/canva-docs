# Quickstart

Copy page

The Canva Button allows you to seamlessly integrate Canva's editor with your website or mobile app. This guide explains everything you need to know to get up and running with the Canva Button.

## Step 1: Sign up for an API key

You need an API key to use the Canva Button.

The Canva Button is only available for users in China. If your users aren't in China, you can't use the Canva Button. There are no plans to make the Canva Button available outside of China.

  * To sign up for the Canva Button, visit [canva.cn/button⁠(opens in a new tab or window)](https://www.canva.cn/button).
  * To sign up for all other Canva APIs, visit [canva.com/developers⁠(opens in a new tab or window)](https://www.canva.com/developers/).



## Step 2: Choose an SDK flavor

The Canva Button SDK is available in the following flavors:

  * Web SDK (HTML)
  * Web SDK (JavaScript)
  * Native SDK (iOS)
  * Native SDK (Android)



Each flavor offers similar features and APIs. Simply choose the one that's the most appropriate to what you're trying to accomplish.

The iOS and Android SDKS are in a closed, invite-only beta.

## Step 3: Set up the Canva Button

After choosing an SDK flavor, read the _Getting started_ guide for that flavor:

  * [Getting started with the HTML API](https://www.canva.dev/docs/button/html/getting-started/)
  * [Getting started with the JavaScript API](https://www.canva.dev/docs/button/javascript/getting-started/)
  * [Getting started with the Android SDK](https://www.canva.dev/docs/button/android/getting-started/)
  * [Getting started with the iOS SDK](https://www.canva.dev/docs/button/ios/getting-started/)



These guides explain how to integrate the Canva Button with your website or mobile app.

## Questions?

If you're not sure if the Canva Button is right for you, have been waiting more than two weeks for your API key to be approved, or have any other questions, [create a support ticket⁠(opens in a new tab or window)](https://canva-external.atlassian.net/servicedesk/customer/portal/68). Someone from the support team will get back to you shortly.
