# Request for translation

Copy page

Canva is available in a diverse range of languages. You can raise a request to have your integration's product catalog and templates translated into any of these languages.

For a complete list of supported languages, refer to [Languages](https://www.canva.dev/docs/print-partnerships/reference/languages/).

Partners can only request the product catalog and templates to be translated to specific languages. The display language of the product catalog and the Canva editor depends on the user's browser language settings. Partners can ignore the browser settings and set a display language with the `opts.locale` parameter in the [`initialize`](https://www.canva.dev/docs/print-partnerships/javascript-api/initialize/) method.

## Raising a request

To raise a request:

  1. Navigate to the [Canva Helpdesk⁠(opens in a new tab or window)](https://canva-external.atlassian.net/servicedesk/customer/portal/68).
  2. Select **Support**.
  3. Select **Homepage Update Request**.
  4. Provide the required details.



Canva requires at least one month to complete the translation.
