# Languages

List of Canva's supported languages.

Copy page

Canva is available in a diverse range of languages. You can [raise a request](https://www.canva.dev/docs/print-partnerships/how-to-guides/request-for-translation/) to have your integration's product catalog and templates translated into some of these languages.

This page contains a list of Canva's supported languages.

Not all languages supported for the product catalog are supported for templates.
