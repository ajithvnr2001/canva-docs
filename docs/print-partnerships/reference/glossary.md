## Volatile parameters

Parameters that:

  * Canva passes into some callback functions, such as the [onProductSelect](https://www.canva.dev/docs/print-partnerships/javascript-api/on-product-select/) function.
  * May change without advanced notice or a deprecation period.
  * Should not be relied upon by an integration (as the integration may break).
