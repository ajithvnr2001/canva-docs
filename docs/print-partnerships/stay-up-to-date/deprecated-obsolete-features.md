# Deprecated and obsolete features

Copy page

As Canva updates the Print Partnership APIs, it's sometimes necessary to deprecate or remove existing features. A feature refers to a functionality, parameter, callback function or API endpoint the Print Partnership SDK provides.

This page contains a list of features that have been deprecated or made obsolete since April 1, 2021.

If you have any questions about deprecated or obsolete features, raise a support ticket via the [Canva Helpdesk⁠(opens in a new tab or window)](https://canva-external.atlassian.net/servicedesk/customer/portal/68/group/37).

## Deprecated features

When a feature is deprecated, it's still available for use, but is no longer in active development. A deprecated feature may be made obsolete in a future release.

Feature| Deprecated on| Description  
---|---|---  
`onArtworkCreate`| June 16, 2021| Replaced with `onMultiArtworkCreate`. See [onMultiArtworkCreate](https://www.canva.dev/docs/print-partnerships/javascript-api/on-multi-artwork-create/).  
`opts.onArtworkCreate`| June 16, 2021| Replaced with `opts.onMultiArtworkCreate`. See [createDesign](https://www.canva.dev/docs/print-partnerships/javascript-api/create-design/#parameters) and [editDesign](https://www.canva.dev/docs/print-partnerships/javascript-api/edit-design/#parameters).  
`opts.previewImageSrc`| April 6, 2021| Replaced with `opts.previewImages`. See [onArtworkCreate](https://www.canva.dev/docs/print-partnerships/javascript-api/on-artwork-create/#parameters).  
`productionFile`| April 6, 2021| Replaced with `productionFiles`. See [Purchase an artwork REST API](https://www.canva.dev/docs/print-partnerships/rest-api/purchase-artwork/#200-success).  
  
## Obsolete features

When a feature is made obsolete, it's no longer available. Partners must use the replacement feature if there's one.

Feature| Made obsolete on| Description  
---|---|---  
`opts.height`| August 11, 2021| No replacement feature available.  
`opts.units`| August 11, 2021| No replacement feature available.  
`opts.width`| August 11, 2021| No replacement feature available.
