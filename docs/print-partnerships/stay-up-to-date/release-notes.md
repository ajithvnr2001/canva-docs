# Release notes

Copy page

Canva publishes release notes every month to keep partners informed about the latest product and partnership developments.

The release notes provide updates about:

  * New features
  * New products and templates
  * Bug fixes and enhancements
  * Marketing and PR updates



This page explains how to subscribe to release notes and provides a list of release notes published so far.

## Subscribe to release notes

To receive updates on product and partnership developments, [subscribe⁠(opens in a new tab or window)](https://mailchi.mp/canva/partner-release-notes) to Canva's monthly release notes.
