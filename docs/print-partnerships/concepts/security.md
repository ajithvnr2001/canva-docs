# Security

Copy page

Canva uses industry-standard practices of workload isolation and data sanitization to normalize the media content that's uploaded to Canva. This normalization process ensures that the user uploaded content is always sanitized and stored in a legitimate media format.

Canva has never recorded any security breaches relating to media uploads.

To learn more about Canva's security practices, read the [Canva Enterprise Security⁠(opens in a new tab or window)](https://drive.google.com/file/d/1XuTCPPuJxntrghM_ckoppbGAZmXY429w/view) white paper.
