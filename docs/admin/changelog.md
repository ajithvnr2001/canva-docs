### October 13, 2026

  * The `email` query parameter of the [List users API](https://www.canva.dev/docs/admin/api-reference/users/list-users/) is now deprecated and will be removed in a future release. Use the [Find user API](https://www.canva.dev/docs/admin/api-reference/users/find-user/) (`POST /v1/users/find`) instead, which accepts the email address in the request body.
