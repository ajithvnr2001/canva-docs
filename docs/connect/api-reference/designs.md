# Designs

The Canva REST APIs for managing designs.

Copy page

The `designs` endpoint lets you interact with the designs present in a user's content library. For more information about Canva designs, see [Canva concepts](https://www.canva.dev/docs/apps/canva-concepts/#designs).

## Designs APIs

  * [Create design](https://www.canva.dev/docs/apps/rest-apis/reference/designs/create-design/): Create a new Canva design.
  * [List designs](https://www.canva.dev/docs/apps/rest-apis/reference/designs/list-designs/): List all the user's designs.
  * [Get design](https://www.canva.dev/docs/apps/rest-apis/reference/designs/get-design/): Get the metadata for one of the user's designs.
  * [Get design pages](https://www.canva.dev/docs/apps/rest-apis/reference/designs/get-design-pages/): Get the metadata for pages in a design.
  * [Get design export formats](https://www.canva.dev/docs/apps/rest-apis/reference/designs/get-design-export-formats/): Get the export formats available for a design.
  * [Get design dataset](https://www.canva.dev/docs/apps/rest-apis/reference/designs/get-design-dataset/): Check if you can autofill a design and what information you can autofill.
