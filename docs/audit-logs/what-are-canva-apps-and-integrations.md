# Canva Apps and Canva Integrations

Explaining the differences between third-party additions to Canva.

Copy page

## Canva Apps

Canva Apps available in the [Canva Apps Marketplace⁠(opens in a new tab or window)](https://www.canva.com/your-apps/) are developed using the [Canva Developers SDK](https://www.canva.dev/docs/apps/apps-inside-canva/). These apps are available to users within the Canva editor, allowing app developers to add new or improved functionally to Canva.

## Canva Integrations

Canva integrations allow third-party app developers to extend key Canva capabilities off-platform. For example, ([Canva for Slack⁠(opens in a new tab or window)](https://www.canva.com/integrations/slack/) and [Canva for ChatGPT⁠(opens in a new tab or window)](https://chat.openai.com/g/g-alKfVrz9K-canva)). These integrations interact with Canva using the [Canva REST APIs](https://www.canva.dev/docs/apps/rest-apis/).
