# Languages

List of Canva's supported languages.

Copy page

Some of the requests that Canva sends to an extension's endpoints include a `locale` property. This property contains a language tag that identifies the user's language. You can (optionally) use this information to customize the user's experience. For example, a [content extension](https://www.canva.dev/docs/extensions/extensions/content-extensions/) might provide content based on the user's language tag.

This page contains a list of languages that Canva supports. The values in the **Code** column are formatted as [IETF BCP 47 language tags⁠(opens in a new tab or window)](https://en.wikipedia.org/wiki/IETF_language_tag) and may appear as values of the `locale` property.

Apps are available in all of Canva's supported languages, but aren't translated for all languages. When an app isn't translated for a language, user-facing text appears in English (US).
