# Release a public app

Learn how to a release a public app to the world.

Copy page

When Canva reviews and approves a [public app](https://www.canva.dev/docs/extensions/platform-concepts/apps/public-apps/), the app is not immediately available via the [Apps Directory⁠(opens in a new tab or window)](https://www.canva.com/apps). You need to initiate the release process via the Developer Portal.

To release a public app:

  1. Navigate to the app via the Developer Portal.
  2. Click **Release**.
  3. Click **Release app**.



When you release an app, a member of the Canva Apps team must manually add the app to the directory, which can take up to a week.

Canva has a separate Developer Portal for China. If you want to release your app in China, you must create and maintain a separate app via [canva.cn/developers⁠(opens in a new tab or window)](https://www.canva.cn/developers).
