# Create a public app

Learn how to create a public app via the Developer Portal.

Copy page

  1. Log in to the [Developer Portal⁠(opens in a new tab or window)](https://www.canva.com/developers).
  2. Navigate to the **Your integrations** page.
  3. Click **Create an app**.
  4. Select **Everyone**.
  5. Navigate through the remainder of the app creation wizard.



You can't convert a public app into a [team app](https://www.canva.dev/docs/extensions/platform-concepts/apps/team-apps/) (or vice-versa). For more information, refer to [Change an app's distribution](https://www.canva.dev/docs/extensions/platform-concepts/apps/change-app-distribution/).

Canva has a separate Developer Portal for China. If you want to release your app in China, you must create and maintain a separate app via [canva.cn/developers⁠(opens in a new tab or window)](https://www.canva.cn/developers).
