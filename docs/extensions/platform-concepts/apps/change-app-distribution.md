# Change an app's distribution

Learn how to change a public app into a team app (and vice-versa).

Copy page

When creating an app, you can choose to make it available to the public or members of a specific [team⁠(opens in a new tab or window)](https://www.canva.com/teams). In the Developer Portal, this choice is referred to as the app's _distribution_.

You can't directly change an app's distribution after creating it. If you create a public app, it is always a public app, and if you create a team app, it is always restricted to members of that particular team.

To bypass this limitation:

  1. Create a new app via the Developer Portal.
  2. Under the **Who is this app for** heading, select the desired distribution type.
  3. Manually copy the metadata from the original app to the new app.



If you create a copy of a released app, you need to submit the new app for review before releasing it (even if the functionality of the app hasn't changed).
