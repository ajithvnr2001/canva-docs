# Create a new version of an app

Learn how to create a new version of an app.

Copy page

  1. Log in to the Developer Portal.
  2. Navigate to the **Your integrations** page.
  3. Click **Create a new version**.



Creating a new version of an app creates a complete copy of the existing app, including its metadata and extensions. Nothing is lost between versions.

You can only create new versions of apps that are in the **Rejected** or **Released** state. If the **Create a new version** button isn't available, verify that it's in a supported state.
