# Java SDKs

An overview of developing apps with Canva's Java SDKs.

Copy page

Canva provides [software development kits](https://www.canva.dev/docs/extensions/backend-development/sdks/) (SDKs) to simplify the process of creating server-side extensions, such as [content](https://www.canva.dev/docs/extensions/extensions/content-extensions/) and [publish extensions](https://www.canva.dev/docs/extensions/extensions/publish-extensions/). The SDKs listed on this page are for the Java programming language.

## [extensions-core](https://www.canva.dev/docs/extensions/backend-development/sdks/java/core/)

The `extensions-core` module provides the fundamental components for developing an extension. If possible, we recommend using one of the other Java SDKs, which are tailored for use with specific frameworks. If you're not using a framework compatible with those SDKs though, this module still provides a lot of useful functionality.

## [extensions-spark](https://www.canva.dev/docs/extensions/backend-development/sdks/java/spark/)

The `extensions-spark` module is built on top of the `extensions-core` module and includes functionality specific to the [Spark⁠(opens in a new tab or window)](http://sparkjava.com) framework.
