# remove-background

Remove the background from an image, leaving the subject on a transparent backdrop.

Copy page

Use `remove-background` when the user wants an image's background removed or made transparent. The tool keeps only the subject. It doesn't crop the image, replace the background with a new scene, or change any other content.

## Example prompt

_"Remove the background from my product photo."_

Pass the image as `sourceMedia`, a `{ "type": "MEDIA", "id": "<media ID>" }` reference to an image already in the user's Canva account. To use a file the user attached, upload it first with [create-upload-url](https://www.canva.dev/docs/apps/mcp/tools/create-upload-url/) and use the returned `mediaId`.

## Example response

IDs, URLs, and tokens below are placeholders; field names and structure are exactly as returned.
    
    
    {
    
      "results": [ { "type": "MEDIA", "id": "MEDIA_EXAMPLE", "version": "1" } ]
    
    }

JSON

Copy

Returns the result in `results` as a `MEDIA` reference to a new image with a transparent background. The source image isn't changed.
