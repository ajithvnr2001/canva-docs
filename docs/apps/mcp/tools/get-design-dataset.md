# get-design-dataset

List the data fields that an existing design can be autofilled with.

Copy page

Use `get-design-dataset` to check whether an existing design has fillable data fields, and to see each field's name and type. Use the field names and types to build the data payload for [autofill-design](https://www.canva.dev/docs/apps/mcp/tools/autofill-design/). To check a Brand Template instead, use [get-brand-template-dataset](https://www.canva.dev/docs/apps/mcp/tools/get-brand-template-dataset/).

Autofill is available to users on Canva Pro, Business, and Enterprise plans.

## Example prompt

_"Can I fill my event flyer with data from our spreadsheet?"_

Requires a `design_id`.

## Example response

IDs, URLs, and tokens below are placeholders; field names and structure are exactly as returned.
    
    
    {
    
      "dataset": {
    
        "event_name": { "type": "text" },
    
        "hero_image": { "type": "image" },
    
        "attendance": { "type": "chart" }
    
      }
    
    }

JSON

Copy

Returns a `dataset` object keyed by field name. Each field has a `type` of `text`, `image`, `chart`, or `sheet`. An empty result means the design can't be autofilled.
