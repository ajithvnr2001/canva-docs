# UI guidelines

Learn about using Canva elements in your product.

Copy page

This article provides guidelines on how to integrate Canva elements, such as buttons, into your product interface.

## Connecting to Canva

### Button types

Use Canva-branded buttons when activating Canva-specific experiences or content from your product. The following examples demonstrate buttons for some common use cases.

#### Do

![](https://www.canva.dev/_next/static/media/do-1.d35906ee.svg)

**DO** use this button for user authentication, when the connection will be sustained.

![](https://www.canva.dev/_next/static/media/do-2.30ad75f8.svg)

**DO** use other action button examples.

### Button guidelines

We recommend using Canva-branded buttons when activating Canva-specific experiences or content from your product. It's acceptable to use text for an action button, without the Canva logo. The following examples demonstrate how to use buttons for some common use cases.

#### Do

![](https://www.canva.dev/_next/static/media/do-3.db75f7dc.svg)

**DO** use the Canva icon inside buttons, with at least `8px` margin on all sides.

![](https://www.canva.dev/_next/static/media/do-5.4e0783c0.svg)

**DO** use alternative buttons without the Canva logo, if needed.

![](https://www.canva.dev/_next/static/media/do-6.112218f2.svg)

**DO** display the Canva button at least as prominently as other third-party options.

#### Don't

![](https://www.canva.dev/_next/static/media/dont-2.cda06052.svg)

**DON'T** use the Canva script logo inside buttons.

![](https://www.canva.dev/_next/static/media/dont-3.eac9025f.svg)

**DON'T** use the Canva icon by itself for a user action. It should be accompanied by text clearly indicating the action that will be taken.

![](https://www.canva.dev/_next/static/media/dont-4.52892959.svg)

**DON'T** use the Canva script logo by itself on a button. It should be accompanied by text clearly indicating the action that will be taken.
