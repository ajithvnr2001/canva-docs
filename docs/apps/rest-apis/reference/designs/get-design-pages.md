# Get design pages

Get the metadata for pages in a design.

Copy page

This API is currently provided as a preview. Be aware of the following:

  * There might be unannounced breaking changes.
  * Any breaking changes to preview APIs won't produce a new [API version](https://www.canva.dev/docs/apps/rest-apis/versions/).
  * Public apps that use preview APIs will not pass the review process, and can't be made available to all Canva users.



Lists metadata for pages in a design, such as page-specific thumbnails.

For the specified design, you can provide `offset` and `limit` values to specify the range of pages to return.

Some design types don't have pages (for example, Canva docs).

## HTTP method and URL path

GET` https://api.canva.com/rest/v1/designs/{designId}/pages`

This operation is rate limited to 100 requests per minute for each user of your app.

## Authentication and authorization

This endpoint requires a valid access token that acts on behalf of a user. For more information, see [Generate an access token](https://www.canva.dev/docs/apps/rest-apis/reference/authentication/generate-access-token/).

### Scopes

The access token must have all the following [scopes](https://www.canva.dev/docs/apps/rest-apis/scopes/) (permissions):

  * `design:content:read`



## Header parameters

`Authorization``string`

Required

Provides credentials to authenticate the request, in the form of a `Bearer` token.

For example: `Authorization: Bearer {token}`

## Path parameters

`designId``string`

Required

The design ID.

## Query parameters

`offset``integer`

Optional

The page index to start the range of pages to return.

Pages are indexed using one-based numbering, so the first page in a design has the index value `1`.

**Minimum:** `1`

**Maximum:** `500`

**Default value:** `1`

`limit``integer`

Optional

The number of pages to return, starting at the page index specified using the `offset` parameter.

**Minimum:** `1`

**Maximum:** `200`

**Default value:** `50`

## Success response

Expand all

If successful, the endpoint returns a `200` response with a JSON body with the following parameters:

`items``DesignPage[]`

The list of pages.

Properties of **items**

`page_number``integer`

The 1-based page number within the design. The first page in a design has the value `1`.

**Minimum:** `1`

**Maximum:** `500`

`design_type``string`

The type of content a design or page contains. The list of design types may grow over time. The `unknown` value represents design types that haven't been added to the list.

**Available values:**

  * `doc`
  * `email`
  * `presentation`
  * `sheet`
  * `whiteboard`
  * `custom`
  * `unknown`



`id``string`

Optional

The ID of the page. This ID is unique within the design and can be used to correlate a page with per-page data from other APIs.

Some designs might not have page IDs, in which case this property is omitted.

`dimensions``PageDimensions`

Optional

The dimensions of a design page, if it is bounded. Design pages for non-bounded designs like Whiteboards and Docs will not include this property.

Properties of **dimensions**

`width``number`

The width of the design page in pixels.

`height``number`

The height of the design page in pixels.

`thumbnail``Thumbnail`

Optional

A thumbnail image representing the object.

Properties of **thumbnail**

`width``integer`

The width of the thumbnail image in pixels.

`height``integer`

The height of the thumbnail image in pixels.

`url``string`

A URL for retrieving the thumbnail image. This URL expires after 15 minutes. This URL includes a query string that's required for retrieving the thumbnail.

`index``integer`

Deprecated

This property is deprecated. Use `page_number` instead, which returns an identical value.

The index of the page in the design. The first page in a design has the index value `1`.

**Minimum:** `1`

**Maximum:** `500`
