# Design types

The Canva REST APIs for listing the design types available in Canva.

Copy page

Design types are combinations of design formats and sizes. When a user creates a new blank design in Canva, they're asked to select a design type, such as "Presentation (16:9)", "Document", or "Instagram Post (Square)". Users can also specify a custom size, which creates a custom design type. For more information about Canva designs, see [Canva concepts](https://www.canva.dev/docs/apps/canva-concepts/#designs).
