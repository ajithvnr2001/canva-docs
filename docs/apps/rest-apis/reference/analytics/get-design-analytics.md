# Get design analytics

Get analytics for a design, including total views and viewers.

Copy page

This API is currently provided as a preview. Be aware of the following:

  * There might be unannounced breaking changes.
  * Any breaking changes to preview APIs won't produce a new [API version](https://www.canva.dev/docs/apps/rest-apis/versions/).
  * Public apps that use preview APIs will not pass the review process, and can't be made available to all Canva users.



To use this API, your app must act on behalf of a user who is a member of a [Canva Enterprise⁠(opens in a new tab or window)](https://www.canva.com/enterprise/) organization.

Gets the aggregated analytics for a design.

The response includes total views, unique viewers, and view duration metrics.

## HTTP method and URL path

GET` https://api.canva.com/rest/v1/designs/{designId}/analytics`

This operation is rate limited to 100 requests per minute for each user of your app.

## Authentication and authorization

This endpoint requires a valid access token that acts on behalf of a user. For more information, see [Generate an access token](https://www.canva.dev/docs/apps/rest-apis/reference/authentication/generate-access-token/).

### Scopes

The access token must have all the following [scopes](https://www.canva.dev/docs/apps/rest-apis/scopes/) (permissions):

  * `design:content:read`



### Capabilities

The user must have at least one of the following [capabilities](https://www.canva.dev/docs/apps/rest-apis/capabilities/):

  * `analytics`



## Header parameters

`Authorization``string`

Required

Provides credentials to authenticate the request, in the form of a `Bearer` token.

For example: `Authorization: Bearer {token}`

## Path parameters

`designId``string`

Required

The design ID.

## Success response

If successful, the endpoint returns a `200` response with a JSON body with the following parameters:

`unique_view_count``integer`

The number of unique viewers.

`total_view_count``integer`

The total number of views.

`average_view_duration_seconds``integer`

Optional

The average view duration in seconds.

`total_view_duration_seconds``integer`

Optional

The total view duration in seconds.

## Example response
    
    
    {
    
      "average_view_duration_seconds": 42,
    
      "total_view_duration_seconds": 5040,
    
      "unique_view_count": 87,
