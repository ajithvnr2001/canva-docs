# Canva REST API versioning

How to manage the Canva REST API version that your app uses.

Copy page

The Canva REST APIs are versioned with a date-based version, which lets Canva make breaking changes without affecting existing apps. For the list of REST API versions, and for how Canva defines a breaking change, see [API versions](https://www.canva.dev/docs/apps/rest-apis/versions/).

The REST API version an app calls is separate from the [app's own version](https://www.canva.dev/docs/apps/versioning-apps/). Creating a new version of an app doesn't change which REST API version it uses.

## Managing API versions for your app

You'll be able to use a setting in the Canva Developer Portal to control which API version your app uses by default. The documentation for managing API versions will be provided when this functionality is available, before any additional REST API versions are released.
