# Apps inside Canva

How to build apps that run in the Canva editor with the Canva Developers SDK.

Copy page

Apps add features to Canva. They run in the browser and are built with standard web technologies, such as JavaScript.

You can use the Canva Developers SDK to create apps inside Canva that import content into Canva, add elements to a user's design, automate common design tasks, and more. You can then either distribute the app publicly through the [Apps Marketplace⁠(opens in a new tab or window)](https://www.canva.com/your-apps), or share it privately with members of your [team⁠(opens in a new tab or window)](https://www.canva.com/for-teams/).

To explore example apps, check out the [starter kit for apps inside Canva⁠(opens in a new tab or window)](https://github.com/canva-sdks/canva-apps-sdk-starter-kit), which is described on [Starter kit](https://www.canva.dev/docs/apps/setting-up-starter-kit/).

## What can apps do?

At their most basic, apps are JavaScript files that run inside an iframe. An app's main UI renders in the side panel of the Canva editor. Canva can also run an app in other contexts, such as an overlay on a selected image, and surfaces intent-based apps wherever their capability is relevant to what a user is doing.

In the iframe, apps can:

  * Use the [Developers SDK](https://www.canva.dev/docs/apps/integrating-canva/) to programmatically interact with the Canva editor.
  * Use the [App UI Kit](https://www.canva.dev/docs/apps/app-ui-kit/) to create a user interface that matches the look and feel of Canva.
  * Use the [Fetch API⁠(opens in a new tab or window)](https://developer.mozilla.org/en-US/docs/Web/API/Fetch_API) to integrate with the app's backend.



## Building with intents

Apps inside Canva are based on intents. An intent is a contract that lets Canva discover your app and present its functionality wherever that capability is relevant to what a user is doing. Each intent defines the set of actions your app must implement, and an app can implement one intent or any combination of them.

All new apps must implement at least one intent. The available intents are:

  * [Content Publisher](https://www.canva.dev/docs/apps/intents/content-publisher/)
  * [Data Connector](https://www.canva.dev/docs/apps/intents/data-connector/)
  * [Design Editor](https://www.canva.dev/docs/apps/intents/design-editor/)
  * [URL Expander](https://www.canva.dev/docs/apps/intents/url-expander/)



For each intent's contract, the technical requirements that apply to every intent, and how to organize an app that implements more than one, see [Intents](https://www.canva.dev/docs/apps/intents/).

## Why create apps?

There are many reasons to create apps, but these are some of the highlights:

  * Reach an audience of 100+ million monthly active users.
  * Create features that improve your own Canva experience.
  * Create apps to improve your team's workflows.
