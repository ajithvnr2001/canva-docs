# Figma resource

Mock up designs for your app.

Copy page

Introducing our Figma resource! This Figma file includes the common Canva components you may need to mock up a design for your app. This file matches the components in our App UI Kit, which you can find in the [starter kit](https://www.canva.dev/docs/apps/setting-up-starter-kit/). Happy designing!

![](https://www.canva.dev/_next/static/media/feature-image.ae25991e.png)

## How to use this file

  1. Download and install font files

[Download font files(opens in a new tab or window)](https://www.canva.dev/assets/fonts.zip)

Canva has a couple of its own custom fonts: Canva Sans and Canva Sans Display. You need to download and install these fonts to properly view the Figma file.

To learn how to use custom fonts with Figma, see [Access local fonts on your computer⁠(opens in a new tab or window)](https://help.figma.com/hc/en-us/articles/360039956894-Access-local-fonts-on-your-computer#h_01FRJ81S9M9SKKQX003DX26HK6).

  2. Download the Figma resource file

[Download App UI Kit Figma resource(opens in a new tab or window)](https://www.figma.com/file/zuskoLLiuDy33IWuUwBtEu/App-UI-Kit-Resource)

Simply download this file and open it in Figma.
