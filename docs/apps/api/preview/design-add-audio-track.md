# addAudioTrack

API reference for the addAudioTrack method.

Copy page

Adds an audio track to the user's design.

## Usage: Add audio track to design
    
    
    import { addAudioTrack } from "@canva/design";
    
    import type { AudioTrack } from "@canva/design";
    
    import type { AudioRef } from "@canva/asset";
    
    
    
    
    const exampleAudioRef = "YOUR_AUDIO_REF" as AudioRef;
    
    
    
    
    const audioTrack: AudioTrack = {
    
      ref: exampleAudioRef
    
    };
    
    
    
    
    await addAudioTrack(audioTrack);

## Parameters

Expand all

`audioTrack``AudioTrack`

RequiredView type definition

The audio track to add to the user's design.

Properties of **audioTrack**

`ref``AudioRef`

RequiredView type definition

A unique identifier that points to an audio asset in Canva's backend.

## Returns

`Promise<void>`

## Permissions

To use this method, the `canva:design:content:write` permission must be enabled for the app. To learn more, see [Permissions](https://www.canva.dev/docs/apps/configuring-intents-permissions/).
