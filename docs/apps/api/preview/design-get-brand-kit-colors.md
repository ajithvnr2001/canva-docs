# getBrandKitColors

API reference for the getBrandKitColors method.

Copy page

Retrieves the current Brand Kit colors for the design.

## Usage: Get Brand Kit colors
    
    
    import { getBrandKitColors } from "@canva/design";
    
    
    
    
    const { palettes } = await getBrandKitColors();

TYPESCRIPT

Copy

## Returns

Expand all

Response containing the current Brand Kit colors for the design. This is a `Promise` that resolves with the following object:

`palettes``BrandKitPalette[]`

View type definition

The list of palettes in the current Brand Kit for the design.

This may be empty if there is no Brand Kit for the design, or the current Brand Kit has no palettes.

Properties of **palettes**

`colors``DesignColor[]`

View type definition

The colors in the palette.

This may be empty if the palette has no colors.

SolidColorSolidColor

UnsupportedColorUnsupportedColor

A solid color from the user's design.

`type``string`

View type definition

The only valid value is `"solid"`.

`color``string`

View type definition

The hexadecimal code representing the color.

This is a 6 character code prefixed with a `#` symbol.

**Example**
    
    
     "#ffffff"

TS

Copy

Represents a color type that is currently not supported by the SDK.

One entry is returned per unsupported color in the design (no deduplication).

`type``string`

View type definition

The only valid value is `"unsupported"`.

## Permissions

To use this method, the `canva:brandkit:read` permission must be enabled for the app. To learn more, see [Permissions](https://www.canva.dev/docs/apps/configuring-intents-permissions/).
