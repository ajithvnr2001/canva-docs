# getDesignMetadata

API reference for the getDesignMetadata method.

Copy page

**This API is a preview**. Preview APIs are unstable and may change without warning. You can't release public apps using this API until it's stable.

Retrieves information about the design.

## Usage: Get design metadata
    
    
    import { getDesignMetadata } from "@canva/design";
    
    
    
    
    const metadata = await getDesignMetadata();
    
    
    
    
    const { title, defaultPageDimensions,  pageMetadata, durationInSeconds } = metadata;

## Returns

Expand all

Information about the design. This is a `Promise` that resolves with the following object:

`pageMetadata``Iterable<PageMetadata>`

View type definition

The information associated with each page of the design.

The order of pages is not guaranteed.

AbsolutePageMetadataAbsolutePageMetadata

UnsupportedPageMetadataUnsupportedPageMetadata

Information about a page within a design with fixed or unbounded dimensions.

`type``string`

View type definition

The type of page.

The only valid value is `"absolute"`.

`id``PageId`

OptionalView type definition

Stable identifier for this page within the design.

`dimensions``PageDimensions`

OptionalView type definition

The dimensions of the page, in pixels.

This may be `undefined` because some types of pages don't have dimensions, such as whiteboards.

Properties of **dimensions**

`width``number`

View type definition

The width of the page, in pixels.

`height``number`

View type definition

The height of the page, in pixels.

`title``string`

OptionalView type definition

The name of the page.

This is optional and will be empty if the user hasn't set a title.

Pages that do not have fixed or unbounded dimensions currently do not return metadata.

`type``string`

View type definition

The type of page.

The only valid value is `"unsupported"`.

`durationInSeconds``number`

View type definition

The duration of the whole design in seconds.

This is the precise value, which differs from what is displayed in the UI as duration in Canva UI is formatted differently.

`title``string`

OptionalView type definition

The title of the user's design.

This is optional and will be `undefined` if the user hasn't set a title.

`defaultPageDimensions``PageDimensions`

OptionalView type definition

The default dimensions that a new page will have when it is added to a design. It is possible for a user to resize a page without resizing the entire design, e.g. by clicking "Expand to Whiteboard". However, there will always be a single set of default dimensions for a design that is applied whenever a new page is created.

This is optional and will be `undefined` if the design is unbounded (e.g. Whiteboard or Doc).

Properties of **defaultPageDimensions**

`width``number`

View type definition

The width of the page, in pixels.

`height``number`

View type definition

The height of the page, in pixels.

`dataset``DataField[]`

Optional

View type definition

The set of data fields that were tagged for Autofill.

This field might be undefined or empty to represent a design that has no tagged fields.

Properties of **dataset**

`label``string`

View type definition

`type``string`

View type definition

**Available values** :

  * `"image"`
  * `"text"`
  * `"chart"`



`brandColorsEnforced``boolean`

Optional

View type definition

Whether brand colors are enforced for this design.

When `true`, a brand admin has switched on Brand Control for colors, so only colors from the Brand Kit can be used. This corresponds to the "Brand Colors" control in the brand settings.

`brandFontsEnforced``boolean`

Optional

View type definition

Whether brand fonts are enforced for this design.

When `true`, a brand admin has switched on Brand Control for fonts, so only fonts from the Brand Kit can be used. This corresponds to the "Brand Fonts" control in the brand settings.

## Permissions

To use this method, the `canva:design:content:read` permission must be enabled for the app. To learn more, see [Permissions](https://www.canva.dev/docs/apps/configuring-intents-permissions/).
