# requestDataTable

API reference for the requestDataTable method.

Copy page

**This API is a preview**. Preview APIs are unstable and may change without warning. You can't release public apps using this API until it's stable.

Retrieves a DataTable from a Data Connector.

The data can be selected through the data selection modal (`dataSelectionDisplay: 'show'`) or fetched directly for a given data source reference (`dataSelectionDisplay: 'hide'`).

## Usage

### Open the data connector selection modal to request data
    
    
    import { requestDataTable } from "@canva/intents/data";
    
    
    
    
    const dataTable = await requestDataTable({
    
      withDataConnector: 'self',
    
      dataSelectionDisplay: 'show',
    
    });

### Request data from the data connector without a preview
    
    
    import { requestDataTable } from "@canva/intents/data";
    
    
    
    
    const dataTable = await requestDataTable({
    
      withDataConnector: 'self',
    
      dataSelectionDisplay: 'hide',
    
      dataSourceRef: { source: 'serialized_content' },
    
    });

The URL of the image file to upload. This can be an external URL or a data URL.

Requirements for external URLs:

  * Must be publicly accessible (i.e. not a localhost URL)

  * Must not contain whitespace
  * Must not contain these characters: `>`, `<`, `{`, `}`, `^`, backticks

Requirements for data URLs:
