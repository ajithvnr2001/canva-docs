# openDesign

API reference for the openDesign method.

Copy page

**This API is a preview**. Preview APIs are unstable and may change without warning. You can't release public apps using this API until it's stable.

Reads (and optionally updates) a specified part of the user's design.

DesignOpenCurrentPageOptionsDesignOpenCurrentPageOptions

DesignOpenAllPagesOptionsDesignOpenAllPagesOptions

Reads (and optionally updates) the current page of the user's design.

## Usage: Read the current page
    
    
    import { openDesign } from "@canva/design";
    
    
    
    
    await openDesign({ type: 'current_page' }, async (session) => {
    
      // Do something with session.page
    
      await session.sync();
    
    });

## Permissions

To use this method, the following permissions must be enabled for the app:

  * `canva:design:content:read`, to read the design
  * `canva:design:content:write`, if the app calls the `sync` method



To learn more, see [Permissions](https://www.canva.dev/docs/apps/configuring-intents-permissions/).

## Rate limit

This method has the following rate limits:

  * Opening the design: 10 requests every 10 seconds
  * Calling the `sync` method: 10 requests every 10 seconds
