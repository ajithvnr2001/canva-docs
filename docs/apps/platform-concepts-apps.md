# Apps

An introduction to apps in the Canva Developers SDK.

Copy page

An _app_ is what you build with the Canva Developers SDK. The Developers SDK provides three surfaces that an app can be built for, and a single app can be built for more than one of them.

## Apps inside Canva

[Apps inside Canva](https://www.canva.dev/docs/apps/apps-inside-canva/) run in the Canva editor and are built with intents. Use this surface to import content into Canva, add elements to a user's design, and automate common design tasks.

## Canva for your platform

[Canva for your platform](https://www.canva.dev/docs/apps/rest-apis/) brings Canva's capabilities into your own web apps and platforms, using the Canva REST APIs. Use this surface to create and sync assets, designs, comments, and more between Canva and your platform.

[Canva for Slack⁠(opens in a new tab or window)](https://www.canva.com/integrations/slack/) and [Canva for ChatGPT⁠(opens in a new tab or window)](https://chat.openai.com/g/g-alKfVrz9K-canva) are examples of what you can build on this surface.

## Canva for AI assistants

[Canva for AI assistants](https://www.canva.dev/docs/apps/mcp/) exposes Canva's design capabilities to an AI assistant through the Canva MCP server. Use this surface so that your users can create, edit, and export designs from the AI tools they already use.
