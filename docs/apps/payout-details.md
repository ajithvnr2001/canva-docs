# Set up payout details

Receiving payments from Canva's monetization programs.

Copy page

Canva's [Premium Apps Program⁠(opens in a new tab or window)](https://www.canva.com/developers/premium-apps-program/) is a monetization program for app developers.

To receive payments from this program, you need to configure payout details via the Developer Portal. These details are configured on a per-app basis.

Monetization is only available for public apps. A private app has no **Grow** section in the Developer Portal.

To set up payout details for an app:

  1. Navigate to the [Your apps⁠(opens in a new tab or window)](https://www.canva.com/developers/apps) page.
  2. Select the app you're configuring payout details for.
  3. Go to **Grow > Monetization**.
  4. Click **Add or edit payout method**.
  5. In the **Details** tab of the **Payments** page, enter your payout details.



If you're creating an app as a member of a team, you must be an administrator of that team to set up payout details. If you don't have access, contact your administrator to update the details.
