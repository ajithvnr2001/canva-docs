# Transitions

An overview of transitions in the App UI Kit.

Copy page

The App UI Kit exposes [design tokens](https://www.canva.dev/docs/apps/app-ui-kit/design-tokens/) for transitions. These transitions add subtle animations to interface elements, such as fading between button states, and can be used to introduce consistent transitions in custom components.

## List of transition tokens

CSS variable| JavaScript variable| Example  
---|---|---  
`--ui-kit-hover-transition`| `hoverTransition`| Hover over me  
`--ui-kit-fade-transition`| `fadeTransition`| Hover over me
