# Reference apps

Reference apps that show how to connect your own platform to Canva.

Copy page

A reference app is a complete, runnable demo of a platform with Canva built into it using the [Canva REST APIs](https://www.canva.dev/docs/apps/rest-apis/). Each one is an app for the Canva for your platform surface: a web app with its own backend that connects a user's Canva account, generates designs from the platform's own data, and hands the user back once they've finished editing in Canva. They are reference implementations for learning purposes. Use them to understand the integration patterns you can apply to your own platform.

Each guide walks through creating an app in the Developer Portal, enabling the REST APIs and the scopes the demo needs, then configuring and running the demo locally.

Both reference apps use brand templates and Autofill, which are available on Canva Pro, Canva Teams, and Canva Enterprise plans. For more information, see [Brand templates](https://www.canva.dev/docs/apps/rest-apis/reference/brand-templates/) and [Autofill](https://www.canva.dev/docs/apps/rest-apis/reference/autofills/).

  * **[Nourish](https://www.canva.dev/docs/apps/reference-apps/nourish/)** : A marketing platform, where marketers generate on-brand campaign materials for multiple channels without leaving the platform.
  * **[Realty Commercial](https://www.canva.dev/docs/apps/reference-apps/realty-commercial/)** : A real estate platform, where agents generate property brochures, social posts, and listing materials from a listing's own data.
