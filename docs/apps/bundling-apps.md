# Bundling apps

How to generate a JavaScript bundle for an app.

Copy page

When you're ready to [submit an app for review](https://www.canva.dev/docs/apps/submitting-apps/), you need to upload the app to the [Developer Portal⁠(opens in a new tab or window)](https://www.canva.com/developers/) as a standalone JavaScript bundle. The [starter kit](https://www.canva.dev/docs/apps/setting-up-starter-kit/) includes a build script that handles this for you.

## How to generate a bundle

  1. Navigate into the starter kit:
         
         cd canva-apps-sdk-starter-kit

BASH

Copy

  2. Run the following command:
         
         canva apps build

BASH

Copy

An `app.js` file will appear in the `dist` directory.




## How to upload a bundle

You can upload the bundle using either the Canva CLI or the Developer Portal.

Canva CLICanva CLI

Developer PortalDeveloper Portal

To build the app and upload the bundle, run the following command from your app's directory:
    
    
    canva apps upload

SHELL

Copy

To upload an existing build instead, use the `--prebuilt` option. For more available options, see [`canva apps upload`](https://www.canva.dev/docs/apps/canva-cli/#upload).

  1. Log in to the Developer Portal.
  2. Navigate to an app via the [Your apps⁠(opens in a new tab or window)](https://www.canva.com/developers/apps) page.
  3. Go to **Inside Canva > Code upload** and, under **App source** , select **JavaScript bundle**.
  4. Upload the `app.js` file.



## Known limitations

  * Canva doesn't support code-splitting, so all code and dependencies must be bundled in a single file. (You can still organize your code into separate files. [`@canva/app-scripts`](https://www.canva.dev/docs/apps/canva-app-scripts/) takes care of the bundling for you.)
  * The size of the app bundle must not exceed 5 MB.
