# Feature examples

Explore our collection of example apps to learn how to implement common features and patterns in your Canva app.

Copy page

The [starter kit for apps inside Canva⁠(opens in a new tab or window)](https://github.com/canva-sdks/canva-apps-sdk-starter-kit/tree/main/examples) contains a collection of example apps that demonstrate how to implement common features and patterns.

The starter kits for apps inside Canva (previously known as the Apps SDK) and the Canva REST APIs (previously known as the Connect APIs) are being combined in a future update. The steps here continue to work until that happens, and will be updated in the future.

## Getting started

The starter kit for apps inside Canva includes atomic examples for our various features. To run the examples locally, follow these steps:

  1. Create a new app in the [Developer Portal⁠(opens in a new tab or window)](https://www.canva.com/developers/apps). For more information, refer to our [Quickstart guide](https://www.canva.dev/docs/apps/quickstart/).

  2. On the app's **Inside Canva** page in the Developer Portal, set **Code upload > App source > Development URL** to `http://localhost:8080`.

  3. Clone the starter kit:
         
         git clone https://github.com/canva-sdks/canva-apps-sdk-starter-kit.git
         
         cd canva-apps-sdk-starter-kit

  4. Install dependencies:
         
         npm install

         npm run start:example
