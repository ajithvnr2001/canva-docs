# Premium apps

Guidelines for designing apps within the Premium Apps Program.

Copy page

This article is for apps that have been accepted into the [Premium Apps Program⁠(opens in a new tab or window)](https://www.canva.com/developers/premium-apps-program/). If your app hasn't been accepted into the program, this article doesn't apply to you. Follow the [Monetization status](https://www.canva.dev/docs/apps/design-guidelines/monetization-status/) guidelines instead.

This guide helps you design apps that are part of the [Premium Apps Program](https://www.canva.dev/docs/apps/premium-apps/). It covers specific design guidelines for gated and non-gated premium apps. Following these guidelines will help you create a seamless and intuitive experience for users, while effectively showcasing the value of your app's premium features.

## Gated premium apps

![Examples of gated premium apps with the premium crown on their icons](https://www.canva.dev/_next/static/media/gated-app-examples.6f5dda97.png)

Canva’s internal teams manage adding the premium crown to your app icon and gating the app for eligible paid users. For completely gated Premium Apps, remove any paywalls that currently exist in the apps, as well as any off-platform login requirements or credit systems. All features in the app should be accessible to Canva users on paid plans.

## Visualizing premium features in freemium or credit-based apps

The following design guidelines apply to **non-gated premium apps**. Gated premium apps aren't required to implement them.

Non-gated Premium apps should follow Canva's native design pattern to distinguish premium features. We use the premium crown icon and pro badge components, sometimes supplemented with a tooltip, as the indication for what the user gets as part of their current Canva plan. Users should be able to take action to upgrade their Canva plan within the immediate proximity of a premium crown icon. To learn more, see [UI requirements](https://www.canva.dev/docs/apps/design-guidelines/premium-apps/#ui-requirements).

Free users are prompted with the account upgrade dialog immediately after clicking on a premium feature. This dialog provides the user with information about upgrading and a call-to-action to complete the upgrade. Therefore, the app's design should focus on the user's task, and let the upgrade dialog handle the upgrade and conversion experience.

## Example app use cases

### Feature-limited apps

The premium crown icon is placed at the end of component labels to highlight premium capabilities.

![](https://www.canva.dev/_next/static/media/01-feature-limited-apps.688751f3.png)

The above example shows free and premium features as configurations blended together in a component. This aligns with how Canva natively displays free and premium features together.

  1. A Free features available for use

  2. B Premium features and capabilities are visible to everyone, but only users on paid Canva plans can use them




### Content-limited apps

Pro badges are placed on the bottom right corner of the components to indicate they're premium content.

![](https://www.canva.dev/_next/static/media/02-content-limited-apps.80dfb5c7.png)

The above example shows free and premium content as cards blended together in a list. This aligns with how Canva natively displays free and premium content together.

  1. A Free content

  2. B Premium content, which is visible to everyone, but only users on paid Canva plans can use them




### Credit-limited AI apps

To align with Canva's direction towards an uncapped fair usage experience, users should not see credit counts.

#### Free user experience

We let Canva Free users know how many times they can try the feature. This allows users to experience the value of the app and motivate them to upgrade to Pro when their free usage run out.

![](https://www.canva.dev/_next/static/media/03-01-credit-limited-apps-free-user-experience.a9ec1a94.png)

  1. A Users see the number of uses they have left in an informational alert, instead of a credit count. It is calculated based on credits remaining and cost per generation.

  2. B Primary button label must include the term "generate", which aligns with Canva's AI feature's microcopy

  3. C Free users see the upgrade button

  4. D Free users see the critical alert when their free uses run out

  5. E The primary button is disabled, because the free usage has run out

  6. F Keep the upgrade button enabled, even when users have reached their usage limit, so they can upgrade their plan at any time




#### Subscribed user experience

Users on paid Canva plans shouldn't see any messaging about usage limits. In rare cases when a user hits a monthly limit, stop them from using the feature and progressively disclose the usage limit information.

![](https://www.canva.dev/_next/static/media/03-02-credit-limited-apps-subscribed-ux.c1feccea.png)

  1. A Don't show any information about the usage limit

  2. B Users who hit the monthly limit should see the critical alert message, informing them to wait until the plan cycle to refresh their usage.

  3. C Primary button is disabled




## Provide a clear freemium app experience

Non-gated premium apps should offer a valuable freemium experience. This gives users the chance to explore your app, understand its value, and see what’s possible before upgrading.

Create a thoughtful balance between free and premium features: enough free content to keep users engaged, while clearly showcasing the added value of upgrading to unlock more.

Free features available to users should remain free and not be retracted, and premium features should be an add-on. This ensures users are still able to produce great output and design from the start.

At the same time, UI should remain the same for Free and Pro users. Users should only experience differences when they see locked features, such as premium assets or advanced settings, rather than a sweeping change across the entire app. This creates a seamless and predictable experience when the user upgrades their Canva plan.

### Do

![](https://www.canva.dev/_next/static/media/04-freemium-experience-dos.c5ab3fca.png)

For Canva Free users:

  1. A Allow users to select free features

  2. B Visually distinguish premium features. They should be immediately visible and trigger the upgrade dialog on user click.

  3. C Provide an upgrade button for users to open the upgrade dialog




For users on paid Canva plans:

  1. D Maintain a consistent experience between free and paid users, and apply subtle visual changes to indicate premiums features that are now available

  2. E Remove the upgrade button for subscribed users




### Don't

![](https://www.canva.dev/_next/static/media/05-freemium-experience-donts.bf650960.png)

  1. A Don't create a drastically different UI between free and subscribed users

  2. B Don't hide premium features for free users

  3. C Don't stop free users from using free features

  4. D Don't leave out highlighting premium features that subscribed users have access to




## UI requirements

The [App UI Kit](https://www.canva.dev/docs/apps/app-ui-kit/) includes two premium crown icons for freemium or credit-based apps:

  * `PremiumAppsProgramProFilledGoldIcon`: The yellow crown. Free users see this icon to draw their attention to premium features.
  * `PremiumAppsProgramProFilledIcon`: The gray crown. Users on paid Canva plans see this icon to let them know they have access to the premium feature.



Use the `isEnabled` method of the monetization API to decide which icon to show. For implementation details, see [Display your UI](https://www.canva.dev/docs/apps/premium-apps/implementing-monetization/#step-4-display-your-ui).

The App UI Kit doesn't include a dedicated pro badge component. To show a pro badge on content cards, place the premium crown icon in the `bottomEnd` slot of the `ImageCard` or `VideoCard` component.

Use these icons to highlight premium features of your app. It helps free users diagnose what is available to them on a free account, and draw in users on paid plans towards the additional features they have access to, and affirm the value of their Canva plan.

This section describes the guidelines that apps must follow when using these icons.

### Premium crown icon

This icon must only be used to highlight premium features that are part of the **Premium Apps Program**.

![](https://www.canva.dev/_next/static/media/01-premium-crown-icon.074cec87.png)

The premium crown icon is used in a few different UI patterns. Its position, either before or at the end of the text, differs depending on where it's used:

  * **In a label:** include the icon immediately after the label text
  * **In a button:** include the icon immediately before the text



#### Include the icon immediately after the label text

When all input components under a label provide premium features, the premium crown icon are added after the label text. This aligns with Canva's native design pattern and provides better readability when the user scans the labels.

Free users are prompted with an upgrade dialog when they interact with the related input components under them.

##### Color selector labels

Premium features utilizing color selectors rely on their labels to describe the feature and visualize the differentiation.

![](https://www.canva.dev/_next/static/media/02-color-selector-free.594ba785.png)

Free users see the yellow premium crown icon. Clicking on the color selector will trigger the upgrade dialog.

![](https://www.canva.dev/_next/static/media/03-color-selector-pro.b04be66a.png)

Users on paid Canva plans see the grey premium crown icon and can use the color selector.

##### Form field labels

Form fields rely on the label to signify that it's a premium feature. Interacting with the related form input or control will trigger the upgrade dialog.

![](https://www.canva.dev/_next/static/media/04-labels-free.1796b4b3.png)

Free users see the yellow premium crown icon appended to the form field label. Clicking on the form input or control will trigger the upgrade dialog.

![](https://www.canva.dev/_next/static/media/05-labels-pro.35bfe9e0.png)

Users on paid Canva plans see the grey premium crown icon and can change the values freely.

###### Do

![](https://www.canva.dev/_next/static/media/06-form-fields-do.c48cac4f.png)

  1. A Include the premium crown icon inlined at the end of the label text

  2. B Do trigger the upgrade dialog when a free user interacts with the related input component




###### Don't

![](https://www.canva.dev/_next/static/media/07-form-fields-dont.efd8a40d.png)

  1. A Don't include the icon in the label when the related inputs have both free and premium options

  2. B Don't trigger the upgrade dialog when the user clicks on the icon

  3. C Don't disable the control or input component unless necessary based on the current context (an action is needed to re-enable it)




##### Switch labels

![](https://www.canva.dev/_next/static/media/08-switch-labels-free.9eb58ff6.png)

Free users see the yellow premium crown icon appended to the label. Clicking the switch triggers the upgrade dialog.

![](https://www.canva.dev/_next/static/media/09-switch-labels-pro.a799fec5.png)

Users on paid Canva plans see the grey premium crown icon and can use the premium feature.

![](https://www.canva.dev/_next/static/media/10-switch-labels-free-desc.1e601ada.png)

![](https://www.canva.dev/_next/static/media/11-switch-labels-pro-desc.69ca0efb.png)

#### Upgrade button as a secondary action for free users

We should provide free users with an upgrade button. When users want subscribe to access premium features they should be able to easily perform the upgrade action. Although premium features are visually highlighted with the Premium Crown Icon, the upgrade button provides a clear action specific to performing an upgrade.

##### Do

![](https://www.canva.dev/_next/static/media/50-upgrade-button-do.df06c376.png)

  1. A Ensure there's only one primary action

  2. B Free users see upgrade button, in the secondary variant, immediately beneath the primary action




###### Exception: when your apps provides more than one action

![](https://www.canva.dev/_next/static/media/52-upgrade-button-exception.b5dafdca.png)

If your app has more than one action you can opt-out of adding the upgrade button. We want the user to be focused on using the app's capabilities, so when there are multiple buttons we should ensure the app is easy to use, and avoid overloading the user with too many buttons.

##### Don't

![](https://www.canva.dev/_next/static/media/51-upgrade-button-dont.70c17dfd.png)

  1. A Upgrade should not appear as a primary action and distract the user from using the app's main feature

  2. B Don't change the icon size

  3. C Don't show this to subscribed users

  4. D Don't change the button text
